# Python
My daily Python learning and practice.

## Day 01 — Hello, Python!

[Open the first program](day_01/hello_python.py)

Topics: `print()`, variables, `input()`, strings, and f-strings.

### Run locally

Install Python 3, download or clone this repository, and open a terminal in its folder:

```bash
python day_01/hello_python.py
```

On Windows, try `py day_01/hello_python.py` if `python` is unavailable. On macOS/Linux, try `python3 day_01/hello_python.py`.

Enter your name when prompted. Blank input uses the name `Learner`.

### Practice yourself

1. Run the program and read each line.
2. Change the welcome message.
3. Add a variable for your favourite game and print it.
4. Run your changes before committing them.
